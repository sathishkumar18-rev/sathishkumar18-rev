# 💫 About Me:

## About Me

I’m an **Automation & Control Engineer** with 3+ years of hands-on experience in **PLC programming, SCADA, motion control, industrial communication, and machine automation**.

My experience includes working with **Mitsubishi, Omron, Siemens, Delta, and Panasonic PLCs**, along with servo systems, VFDs, HMIs, SCADA platforms, and industrial networks. I’ve worked on machine commissioning, PLC retrofits, troubleshooting, production-line integration, traceability, and communication between industrial devices.

I’m particularly interested in the connection between **OT and IT** — building systems where PLCs and industrial equipment can communicate with databases, applications, IoT platforms, and modern software technologies.

### 🔧 Technical Interests

* PLC Programming — Ladder, Structured Text, FBD & SFC
* Industrial Communication — Modbus, EtherNet/IP, EtherCAT, PROFINET, OPC UA, MQTT
* Mitsubishi MC Protocol / SLMP & Omron FINS
* SCADA & Industrial Data Acquisition
* Motion Control & Servo Systems
* PLC ↔ PC / Database Communication
* Node-RED & IIoT
* Industrial IoT & Edge Computing
* SQL & Industrial Data Systems
* TCP/IP & Socket Programming
* Python & PowerShell for industrial automation
* .NET / C# for PLC communication tools
* Industrial Cybersecurity & OT Networking
* AI-assisted Industrial Automation

### 🚀 What I'm Building

I’m using GitHub to document practical projects that bridge **PLC automation and software engineering**, including:

`PLC → Industrial Protocol → PC/Edge Application → Database/API → IIoT Platform`

My goal is to develop reusable tools, protocol clients, simulators, dashboards, and industrial communication projects while continuously expanding from traditional automation toward **IIoT, industrial software, and OT/IT integration**.

> **From PLC logic to industrial software — building practical solutions at the intersection of Automation, IT and IIoT.**
